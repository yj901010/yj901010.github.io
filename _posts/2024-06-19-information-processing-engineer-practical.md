> 2024년 1회 정보처리기사 실기 합격 후기를 간결하게 다시 정리했다.

원문: https://it-r-b.tistory.com/124

## 결과

2024년 1회 정보처리기사 실기에 합격했다.

시험 직후 가채점에서는 합격 여부가 애매하다고 생각했지만 최종 점수는 69점이었다.

높은 점수를 목표로 준비한 시험은 아니었고, 합격선 이상을 안정적으로 만드는 데 초점을 맞췄다.

## 공부 방식

내가 사용한 방식은 기출 중심이었다.

1. 먼저 실기 기출문제를 풀었다.
2. 모르는 문제와 개념을 표시했다.
3. 해당 개념을 다시 공부했다.
4. 자주 틀리는 내용은 반복해서 확인했다.
5. 다시 기출을 풀며 회상했다.

책을 처음부터 끝까지 정독한 뒤 문제를 푸는 방식보다, 문제를 먼저 만나고 필요한 개념을 채우는 방식이 나에게는 더 잘 맞았다.

## 시험 전에 다시 본 것

시험 직전에는 특히 다음 내용을 다시 확인했다.

- 블랙박스 / 화이트박스 테스트
- 결합도 / 응집도
- 디자인 패턴
- 네트워크와 보안 개념
- 과거 기출에서 반복해서 틀린 내용

## 시험에서 느낀 점

이론을 알고 있어도 답안을 쓰는 순간 사소한 실수를 할 수 있었다.

약어와 프로토콜 명칭처럼 정확한 표기가 필요한 문제에서는 '알고 있다'와 '정확히 써낼 수 있다' 사이에 차이가 있었다.

주관식 시험을 준비할 때는 내용을 읽는 것만으로 끝내지 않고 직접 답을 써보는 연습이 필요했다.

## 이후 공부에 남은 것

정보처리기사 범위는 넓어서 각각의 주제를 깊게 다루는 시험은 아니다.

하지만 운영체제, 네트워크, 데이터베이스, 소프트웨어 설계, 보안 등의 용어를 다시 접하면서 CS 공부에서 어떤 영역이 있는지 큰 지도를 만드는 데는 도움이 됐다.

현재 다시 공부한다면 자격증 암기와 실무 지식은 구분할 것이다.

시험을 위해 외웠던 개념 중 실제 백엔드 개발에 연결되는 주제는 별도로 깊게 공부하는 편이 더 중요하다.
